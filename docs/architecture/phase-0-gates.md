# Phase 0 Exit Gates

Phase 0 can close only when:

- [x] product boundary: ASEN extends Pi
- [x] no External runtime dependency decision
- [x] exact upstream audit baselines recorded
- [x] initial provenance/license policy
- [x] authority and threat model
- [x] engineering lifecycle/state model
- [x] testing/evidence strategy
- [x] P0 capability contracts for core boundaries
- [x] architecture CI gate
- [ ] architecture CI green on final Phase 0 candidate
- [ ] independent final review of the Phase 0 candidate
- [ ] final candidate identity/evidence recorded

Runtime implementation is explicitly outside Phase 0.
