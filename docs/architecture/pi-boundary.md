# Pi Boundary

## Pi owns
- model/provider execution and authentication
- model selection primitives
- conversation/session runtime
- context/compaction primitives
- TUI
- built-in read/write/edit/bash tools
- extension APIs
- Skills discovery/execution
- package loading

## ASEN owns
- Flow and complexity/risk routing
- agent delegation policy and edit scopes
- task state
- Spec/Test/Review/Verify workflow
- candidate identity and evidence
- persistent engineering memory
- doctor/backup/rollback/migration for ASEN-owned state
- Radar and Capability Registry

## Rule
If a capability is already a stable Pi primitive, ASEN composes it rather than reimplementing it.
