# v1 Scope

ASEN v1 is an executable Pi-native harness foundation, not a replacement shell.

Included:
- deterministic workflow state
- risk routing
- bounded delegation
- candidate/evidence identity
- structured review and verification
- local persistent memory with full-text search
- transactional lifecycle primitive and Doctor
- upstream Radar classifier
- Pi extension and native Skill packaging
- Linux/Windows CI

Deliberately deferred beyond the v1 foundation:
- cloud memory/sync
- autonomous upstream adoption
- full-screen custom TUI
- multi-provider coding-agent adapters
- release automation
- advanced worktree manager
- telemetry backend

Deferred items are extension work, not hidden prerequisites for the core safety guarantees.
