# License and Attribution Policy

Phase 0 policy:
1. Prefer independent implementation from observable contracts.
2. Do not copy source merely to achieve parity.
3. Any reused source must receive a provenance record before merge.
4. Preserve copyright/license notices required by the source license.
5. Do not reuse upstream names, logos, or branding as ASEN branding.
6. Dependencies require license review appropriate to distribution.
7. Generated behavioral contracts must describe observable behavior rather than reproduce protected documentation text.

A full dependency/license inventory becomes mandatory before the first distributable release.
